如何验证这份存证
  1. 下载原文件（如 种子-三部曲合集.md）与对应的 .ots 证明。
  2. 安装 OpenTimestamps：pip install opentimestamps。
  3. 验证：ots verify 种子-三部曲合集.md.ots。
  4. 若显示 Success! 与比特币区块高度，则证明该文件在此时间之前已存在，且未被篡改。
  5. 也可直接比对 SHA256：sha256sum 种子-三部曲合集.md。
如何在 IPFS 上固定这些文件
  1. 使用本地 IPFS 节点：ipfs add --raw-leaves --cid-version=1 <file>，对比 CID 是否与下表一致。
  2. 通过 Pinata 固定：登录 app.pinata.cloud，上传文件或用 "Pin by CID" 填入下表 CID。
  3. 通过 Web3.Storage 固定：w3 up <file>（需 w3 CLI 与免费账号）。
  4. 固定后，文件可通过 https://ipfs.io/ipfs/<CID> 全球访问。
